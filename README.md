Netflix Clone

A responsive frontend clone of Netflix built to replicate the user interface, layout structure, and browsing experience.

🚀 Features
Responsive Design: Adapts smoothly across different screen sizes.
Netflix UI Elements: Recreates the signature dark theme, hero banner with background video/imagery, and scrollable content rows.
Modern Layout: Built with clean structuring to mimic the core streaming dashboard layout.
🛠️ Built With
HTML5 - For content structure and semantic markup CSS3 - For styling, flexbox/grid layouts, and animations

📦 Getting Started
To view or run this project locally:

Clone or download this repository to your local machine.
Open the index.html file in any modern web browser.
